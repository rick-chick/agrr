# ゲート判定（G2 / G3）

人間が行っていた **方針転換・レビュー** をサブエージェントが機械判定する。出力は JSON。

## 共通 JSON 形

```json
{
  "gate": "overlap-ux-guard | plan-review",
  "verdict": "pass | fail | blocked",
  "summary": "一行要約",
  "findings": ["観測ベースの指摘"],
  "mandatory_corrections": ["次の修正で必須"],
  "blocked_reason": "blocked のときのみ"
}
```

| verdict | 意味 |
|---------|------|
| `pass` | 次フェーズへ |
| `fail` | 親エージェントが修正して同ゲートを再実行（G3 は最大2回） |
| `blocked` | ユーザー問い合わせ（依頼と事実の矛盾） |

---

## G2: 重複・UXガード（overlap-ux-guard）

**タイミング**: フェーズ 4 深掘りの直後。新画面・多機能 UI 案を止める。

### 入力

- `tmp/product-gap/current-state.md`
- `tmp/product-gap/theme-deep-dive.md`

### 判定基準（1つでも該当 → 原則 `fail`）

| # | 質問 | fail 時の修正 |
|---|------|----------------|
| G2-1 | 提案が **新ルート・新ダッシュボード** か？ | 既存ルートへの強化に差し替え |
| G2-2 | 既存画面と **同じタスク一覧** を二重表示するか？ | 一覧は1画面に限定（通常は実行画面） |
| G2-3 | 天候・GDD を **チャート/カード大量** で載せるか？ | 短い注意＋既存気候画面へ誘導 |
| G2-4 | 全農場タスクを **1リストに混ぜる** か？ | 農場別サマリ＋件数のみ |
| G2-5 | v1 に **集約 API 新設** が必須とされているか？ | フロント並列 or 後続 issue に送る |
| G2-6 | 深掘りに **実装コード・コンポーネント設計** が含まれるか？ | 削除し画面役割レベルに戻す |

### pass の条件

- デフォルトが **既存画面強化**
- 入口 / 実行 / 予定表 / 分析（気候）の **役割分担** が言える
- v1 の情報追加が **件数・1行注意・遅延日数** 程度に収まる見込み

### blocked の例

- ユーザーが「新ダッシュボード必須」と明示し、プロダクト方針（計画アプリ）と両立しない
- 既存機能の有無が調査で確定できない

## G3: 計画レビュー（plan-review）

**タイミング**: `enhancement-plan.md` 完成後、モック・起票の前。

### 入力

- `tmp/product-gap/enhancement-plan.md`
- `tmp/product-gap/overlap-ux-gate.json`（G2 pass 前提）
- `tmp/product-gap/current-state.md`

### 判定基準

| # | 質問 | fail 時 |
|---|------|---------|
| G3-1 | **画面ごとに1役割** が表で明示されているか？ | 役割表を追加 |
| G3-2 | **v1 が3点以内**（推奨）に固定されているか？ | v2 へ送る |
| G3-3 | **農場1件ユーザー** への価値が書かれているか？ | `/work` 過剰投資を削り実行画面へ |
| G3-4 | **やらないこと** が列挙されているか？ | スコープ外を追記 |
| G3-5 | issue 化可能な **観測可能な完了条件** に落ちるか？ | 曖昧語を具体化 |
| G3-6 | `/work` と `/plans/:id/work` の **重複** が残っていないか？ | サマリ vs 実行に再分割 |

### pass の条件

- レビューで **「新画面不要・既存強化で足りる」** と明示できる
- v1 着手順が UX リスクの低い順になっている

## 人間介入 → ゲート対応表

| 人間が言っていたこと | 自動化 |
|---------------------|--------|
| 既存と役割が被る | G2-1, G2-2 |
| その状態で新機能は要る？ | G2 → 強化方針へ強制 |
| コード書くな | G2-6、スキル禁止節 |
| 詳細に引きずられて UX 悪化 | G2-3, G2-4 |
| 強化方向で整理 | フェーズ 6 |
| レビュー | G3 |
| 画面モック | フェーズ 8 |
| issue 起票 | フェーズ 9 |
